Module 1

What This Project Does

Financial markets have regimes: extended stretches of calm punctuated by crises (the 2008 GFC, COVID-19, the 2022 rate-hike sell-off, ...). A trading desk that can detect a regime shift in real time -- even a few days early -- gains a decisive edge in risk management.

The central insight of this project: encode each day's market data as a quantum state in a Hilbert space, then measure geometric properties of the resulting state manifold. When the market transitions between regimes, the geometry of the manifold changes -- curvature spikes, spectral gaps collapse, entanglement structure reorganizes. These geometric observables become crisis detectors.

Headline Result
Berry Phase Rate: d = 0.72 OOS
Out-of-sample Cohen's d via walk-forward evaluation, with 30% fewer false alarms per year than a Random Forest baseline (2.5 vs. 3.6/yr).

The paper, Geometric Observables for Financial Regime Detection, compares 46 methods across 17 historical crises (2000--2024): 22 geometric QCML channels, 18 classical baselines (Random Forest, GARCH, Hidden Markov, BOCPD, VIX, ...), and 6 ensembles.

This course walks through the entire pipeline, from downloading prices to the final statistical horse race, mapping every step to the mathematics you already know.

Module 2

From Market Data to Feature Space

The raw input is daily adjusted close prices for two ETFs: SPY (S&P 500) and DIA (Dow Jones), downloaded via yfinance. From these two price series, we build a 13-column feature matrix capturing returns, volatility at two scales, momentum at two scales, and cross-sectional statistics.

Step 1: Log Returns and Rolling Statistics

The feature engineering is deliberately simple -- no proprietary signals, no alternative data. For each symbol we compute:

  • Log return: $r_t = \ln(P_t / P_{t-1})$
  • 5-day rolling volatility: $\sigma^{(5)}_t = \mathrm{std}(r_{t-4:t})$
  • 20-day rolling volatility: $\sigma^{(20)}_t$
  • 5-day momentum: $(P_t - P_{t-5})/P_{t-5}$
  • 20-day momentum: $(P_t - P_{t-20})/P_{t-20}$

With 2 symbols that gives $2 \times 5 = 10$ per-asset features. Three cross-sectional features are added: 5-day rolling cross-correlation, 20-day cross-volatility dispersion, and average return. Total: 13 features.

Step 2: StandardScaler + PCA + Sphere Normalization

Before embedding into Hilbert space, the features are standardized (zero mean, unit variance), then projected via PCA to $n_{\mathrm{pca}}$ components (typically 8). Finally, a soft normalization maps each feature vector toward the unit sphere, preventing any single day from dominating the Hamiltonian scale.

$$\tilde{x}_t = \frac{x_t^{\mathrm{pca}}}{\|x_t^{\mathrm{pca}}\| + \epsilon}, \qquad \epsilon \sim 10^{-10}$$

This is the "soft" normalization mode used by default. The result is a time series of approximately unit vectors on $S^{n_{\mathrm{pca}}-1}$ -- each day is a point in a low-dimensional feature space, ready for the QCML embedding.

Module 3

The QCML Embedding

This is the core mathematical construction. Given a feature vector $x \in \mathbb{R}^d$, we build a Hermitian operator $H(x)$ whose ground state $|\psi(x)\rangle$ defines a map from the feature space into a projective Hilbert space. As $x$ varies, $|\psi(x)\rangle$ traces a curve on the quantum state manifold, and the geometry of this manifold encodes information about the data structure.

Hermitian Operators $\{A_k\}$

The embedding requires one Hermitian operator $A_k$ per feature dimension $k = 1, \ldots, d$. These live in $\mathrm{Herm}(\mathcal{H})$ where $\dim \mathcal{H}$ is chosen between 4 and 16 per observable (tuned via ablation, not a single global value). Three construction methods:

  • Random (default for production): seeded random Hermitian matrices $A_k = (M + M^\dagger)/2$ where $M$ has i.i.d. complex Gaussian entries. Different seeds produce different embeddings, breaking Kramers-type degeneracies.
  • Pauli tensor products: for $n$-qubit systems ($\dim \mathcal{H} = 2^n$), use tensor products of Pauli matrices $\{\sigma_i \otimes \sigma_j \otimes \cdots\}$.
  • Gell-Mann SU(N) generators: the $N^2 - 1$ traceless Hermitian generators of $\mathfrak{su}(N)$, with optional PCA eigenvalue scaling.

The Error Hamiltonian

$$H(x) = \frac{1}{2} \sum_{k=1}^{d} (A_k - x_k \mathbb{I})^2$$

This is a sum of squared "error" terms. Each operator $A_k$ is trying to have eigenvalue $x_k$; the ground state $|\psi(x)\rangle$ is the state that simultaneously comes closest to being an eigenstate of every $A_k$ with eigenvalue $x_k$. When the $A_k$ don't commute, this is a nontrivial optimization -- the ground state encodes the best compromise, and the geometry reflects the frustration.

Code -- core.py:271-294
def error_hamiltonian(self, x): H = np.zeros( (self.hilbert_dim, self.hilbert_dim), dtype=np.complex128) for k, (A_k, x_k) in enumerate( zip(self.operators, x)): diff = A_k - x_k * self._identity H += 0.5 * (diff @ diff) return H
What This Computes
1 Allocate a zero matrix of size $n \times n$ in $\mathbb{C}$, where $n$ = hilbert_dim.
2 For each feature $k$: compute the deviation operator $(A_k - x_k \mathbb{I})$, square it, accumulate with weight $\tfrac{1}{2}$.
3 The result $H(x)$ is Hermitian and positive semidefinite (sum of squared Hermitian operators). Its ground state is the quasi-coherent state.

Ground State via Diagonalization

The ground state $|\psi(x)\rangle$ is the eigenvector of $H(x)$ corresponding to its smallest eigenvalue, found by exact diagonalization via numpy.linalg.eigh (exploiting Hermiticity for $O(n^3)$ cost with guaranteed real eigenvalues).

The cache is important: Berry curvature computation requires evaluating $|\psi(x)\rangle$ at four nearby points per plaquette, so caching avoids redundant diagonalizations. As the market evolves day by day, $|\psi(x_t)\rangle$ traces a path on the projective Hilbert space $\mathbb{C}P^{n-1}$.

Comprehension Check
The error Hamiltonian $H(x) = \frac{1}{2}\sum_k (A_k - x_k \mathbb{I})^2$ is positive semidefinite, with $E_0(x) = 0$ if and only if all $A_k$ share a simultaneous eigenstate with eigenvalues $x_k$. Under what condition on the operators $\{A_k\}$ is this achievable for every $x \in \mathbb{R}^d$?
A The $A_k$ must be traceless
B The $A_k$ must mutually commute: $[A_j, A_k] = 0$ for all $j, k$
C The $A_k$ must form a representation of $\mathfrak{su}(d)$
D The Hilbert space dimension must equal $d$
$E_0(x) = 0$ for all $x$ requires a simultaneous eigenbasis for all $A_k$, which is exactly the condition $[A_j, A_k] = 0$ for all pairs. When the operators don't commute, $E_0(x) > 0$ everywhere, and the "frustration" creates nontrivial geometry on the state manifold. This is the regime where the QCML embedding is interesting: the Berry curvature $F_{ab}$ vanishes identically when all $[A_j, A_k] = 0$.
Module 4

Four Geometric Observables

From the single QCML embedding $x \mapsto |\psi(x)\rangle$, we extract four independent observables. Each measures a different aspect of the quantum geometry and responds to different crisis signatures. Think of them as four instruments reading the same underlying manifold from orthogonal perspectives.

1. Berry Phase Rate

The headline observable. The Berry curvature $F_{ab}$ is the field strength of the Berry connection on the state manifold. We compute it via the discrete plaquette (Wilson loop) method -- gauge-invariant by construction.

$$F_{ab}(x) = -2\,\mathrm{Im}\langle \partial_a \psi | \partial_b \psi \rangle$$

The plaquette method evaluates $|\psi\rangle$ at four corners of an infinitesimal square in the $(a, b)$ plane and computes the Wilson loop:

$$W = \langle\psi_{00}|\psi_{10}\rangle\langle\psi_{10}|\psi_{11}\rangle\langle\psi_{11}|\psi_{01}\rangle\langle\psi_{01}|\psi_{00}\rangle, \qquad F_{ab} \approx \frac{\mathrm{Im}\,\ln W}{\epsilon^2}$$
qcml_geometry/core.py:419-457Python
def berry_curvature_2d(self, x, indices=(0, 1), epsilon=1e-5): x = np.asarray(x).flatten() a, b = indices # Four corners of the plaquette x00 = x.copy() x10 = x.copy(); x10[a] += epsilon x11 = x.copy(); x11[a] += epsilon; x11[b] += epsilon x01 = x.copy(); x01[b] += epsilon # Ground states at each corner psi00 = self.quasi_coherent_state(x00) psi10 = self.quasi_coherent_state(x10) psi11 = self.quasi_coherent_state(x11) psi01 = self.quasi_coherent_state(x01) # Wilson loop overlaps U01 = np.vdot(psi00, psi10) U12 = np.vdot(psi10, psi11) U23 = np.vdot(psi11, psi01) U30 = np.vdot(psi01, psi00) wilson = U01 * U12 * U23 * U30 berry_phase = np.imag(np.log(wilson)) return berry_phase / (epsilon ** 2)

The Berry Phase Rate detector takes $|F_{01}(x_t)|$, computes the absolute day-over-day change $|\Delta F_{01}|$, smooths with a 20-day rolling mean, then standardizes via an expanding-window z-score. Spikes in this z-score signal that the manifold geometry is changing anomalously fast.

2. Spectral Entropy

The Shannon entropy of the excitation spectrum of $H(x)$, weighted by energy gaps above the ground state:

$$w_n = \frac{E_n - E_0}{\sum_{n' \geq 1}(E_{n'} - E_0)}, \qquad S(x) = -\sum_{n \geq 1} w_n \ln w_n$$

High entropy means the excitation spectrum is broadly distributed (many modes contribute) -- this is the "normal" regime. Low entropy means spectral collapse: a few modes dominate, the gap structure has reorganized. This observable is sensitive to the spectral geometry of the Hamiltonian, complementary to the Berry curvature which captures fiber bundle geometry.

qcml_geometry/core.py:789-808Python
def spectral_entropy(self, x, c=1.0): eigenvalues = self.full_spectrum(x) E0 = eigenvalues[0] excitations = eigenvalues[1:] - E0 excitations = np.maximum(excitations, 1e-15) weights = excitations / np.sum(excitations) return float(-np.sum( weights * np.log(weights + 1e-15)))

3. Hamiltonian Sensitivity

The variance of the Hamiltonian perturbation $\Delta H = H(x_{t+1}) - H(x_t)$ measured in the current ground state:

$$\mathrm{Var}_{|\psi\rangle}(\Delta H) = \langle\psi|\Delta H^2|\psi\rangle - \langle\psi|\Delta H|\psi\rangle^2$$

This is the quantum mechanical energy uncertainty of the perturbation. Near a quantum phase transition, susceptibilities diverge; analogously, when the market is at a regime boundary, the ground state becomes highly sensitive to small parameter shifts. Large $\mathrm{Var}(\Delta H)$ signals the system is near a critical point.

qcml_geometry/core.py:833-857Python
def hamiltonian_sensitivity(self, x_curr, x_next): psi = self.quasi_coherent_state(x_curr) H_curr = self.error_hamiltonian(x_curr) H_next = self.error_hamiltonian(x_next) DH = H_next - H_curr DH_psi = DH @ psi mean_DH = np.real(np.vdot(psi, DH_psi)) mean_DH2 = np.real(np.vdot(DH_psi, DH_psi)) return float(max(mean_DH2 - mean_DH ** 2, 0.0))

4. Reduced State Purity

Bipartition the Hilbert space as $\mathcal{H} = \mathcal{H}_A \otimes \mathcal{H}_B$, partial-trace out subsystem $B$, and measure the purity of the reduced state:

$$\rho_A = \mathrm{Tr}_B(|\psi\rangle\langle\psi|), \qquad \mathcal{P} = \mathrm{Tr}(\rho_A^2) \in [1/d_A,\; 1]$$

Purity $\mathcal{P} = 1$ means no entanglement between subsystems; $\mathcal{P} = 1/d_A$ is maximally entangled. During crises, cross-sector correlations spike, and this shows up as increased entanglement (lower purity) in the QCML embedding. This was the top-ranked offline detector ($d = 0.83$), though it proved fragile on out-of-sample holdout data.

def reduced_state_purity(self, x, partition=(2, 4)): dim_A, dim_B = partition psi = self.quasi_coherent_state(x) # Reshape |psi> into bipartite matrix psi_matrix = psi.reshape(dim_A, dim_B) # Reduced density matrix: rho_A = psi @ psi^dagger rho_A = psi_matrix @ psi_matrix.conj().T # Purity = Tr(rho_A^2) return float(np.real( np.trace(rho_A @ rho_A)))

Module 5

From Observable to Detector

A geometric observable like Berry curvature produces a raw time series of numbers. To turn it into a detector -- one that fires a "crisis alert" signal -- we need a normalization scheme that answers: "how unusual is today's value compared to everything we've seen so far?"

Expanding-Window Z-Score

The key constraint is causality: the detector at time $t$ may only use data from times $\{1, \ldots, t-1\}$. No peeking at the future. The expanding-window z-score achieves this:

$$z_t = \frac{\bar{v}_t - \mu_{<t}}{\sigma_{<t}}, \qquad \mu_{<t} = \frac{1}{t-1}\sum_{s=1}^{t-1}\bar{v}_s, \quad \sigma_{<t} = \mathrm{std}(\bar{v}_{1:t-1})$$

where $\bar{v}_t$ is the rolling-mean-smoothed observable value (window = 20 days). The smoothing removes day-to-day noise; the expanding normalization adapts to the evolving baseline.

Code -- observables.py:2488-2511
def _expanding_zscore(raw_values, rolling_window, min_expanding, T, skip_nan_start=0): """Expanding-window z-score of rolling-mean.""" import pandas as pd rolling_vals = ( pd.Series(raw_values) .rolling(window=rolling_window, min_periods=1) .mean().values) z_scores = np.full(T, np.nan) start = max(min_expanding, skip_nan_start) for t in range(start, T): past = rolling_vals[skip_nan_start:t] past_valid = past[~np.isnan(past)] if len(past_valid) < 10: continue mu = np.mean(past_valid) sigma = np.std(past_valid, ddof=1) if sigma > 1e-12: z_scores[t] = (rolling_vals[t] - mu) / sigma else: z_scores[t] = 0.0 return z_scores
Step by Step
1 Smooth the raw observable with a rolling mean (window = 20 days, allowing partial windows at the start).
2 Initialize all z-scores to NaN (we can't compute a meaningful z-score until we have enough history).
3 For each day $t$ from min_expanding onward: gather all past smoothed values (strictly before $t$).
4 Need at least 10 valid past values to compute reliable statistics. Otherwise skip.
5 Compute the mean and standard deviation of the past window. If $\sigma > 0$, standardize: $z_t = (\bar{v}_t - \mu) / \sigma$.
6 The expanding window grows every day, so the baseline becomes more robust over time while remaining strictly causal.

The output $z_t$ is the detector's regime score. Large positive values (e.g., $z > 2$) indicate the observable is anomalously elevated compared to its historical distribution -- a potential crisis signal.

The Horse Race

With 46 detection methods and 17 crises, we need a rigorous statistical framework to answer: which methods actually work, and how confidently can we rank them?

The 46 Contenders

  • 22 QCML geometric channels: Berry Phase Rate, Spectral Entropy, Hamiltonian Sensitivity, Reduced State Purity, plus 18 others (Fubini-Study velocity, geodesic curvature, spectral gap, Chern number, quantum relative entropy, level spacing ratio, ...)
  • 18 classical baselines: Random Forest, GARCH(1,1), Hamilton Markov-switching, BOCPD, Isolation Forest, VIX, Rolling Vol, CUSUM, EWMA, Mahalanobis distance, LSTM autoencoder, kernel PCA, ...
  • 6 ensemble methods: Flat rank, hierarchical rank, regime-adaptive fusion, SPRT, ...

The 17 Crises (2000--2024)

Each crisis has a defined start and end date. The crises span a wide range of mechanisms: the Dot-Com crash (2000), September 11 (2001), the Quant Crisis (2007), the Global Financial Crisis (2008), the Flash Crash (2010), the Euro Crisis (2011), the Taper Tantrum (2013), China (2015), Brexit (2016), Volmageddon (2018), Q4 Selloff (2018), the Repo Crisis (2019), COVID-19 (2020), Meme/Archegos (2021), Rate Hikes (2022), SVB (2023), and the Carry Unwind (2024).

Effect Size: Cohen's d

For each (method, crisis) pair, we compute the Cohen's d between the method's scores during the crisis window and its scores during normal periods. Large $d$ means the detector clearly separates crisis from calm.

$$d = \frac{|\bar{x}_{\text{crisis}} - \bar{x}_{\text{normal}}|}{s_{\text{pooled}}}, \qquad s_{\text{pooled}} = \sqrt{\frac{(n_c - 1)s_c^2 + (n_n - 1)s_n^2}{n_c + n_n - 2}}$$

The confidence interval on $d$ is computed via circular block bootstrap ($n = 10{,}000$ resamples) to account for serial correlation in the time series. This is critical -- naive i.i.d. bootstrap would understate the CI width.

The Friedman Test

With 46 methods and 17 crises, we have a matrix of ranks. The Friedman test is a non-parametric alternative to repeated-measures ANOVA that asks: "Do the methods differ significantly in their median rank across crises?"

Walk-Forward Evaluation

The offline rankings (computed on the full 17-crisis panel) are retrospective: the detector has seen all the data. To test real-world viability, we use walk-forward evaluation with nested HPO (Optuna with TPE sampler):

  • Split the timeline into overlapping windows
  • For each window: train on past data, tune hyperparameters on a validation split, freeze the model, evaluate on the next unseen crisis
  • The test set is never used for tuning
  • Repeat across 9 windows; report median $d$ and win rate
Comprehension Check
A method has offline $d = 0.95$ (top 3 in the retrospective ranking) but walk-forward $d = 0.35$ (below the RF baseline). The most likely explanation is:
A The Friedman test has a type I error for this method
B The method (or its hyperparameters) overfit to the retrospective crisis panel via HPO, and fails to generalize out-of-sample
C The block bootstrap CI must be too narrow
D The crisis definitions must be wrong for the walk-forward windows
This is exactly what happened with Reduced State Purity in this study: offline $d = 0.83$ (#1 of 46), but it collapsed to $d = 0.26$ on the holdout set. The HPO process can tune hyperparameters to match the specific crises in the retrospective panel, producing artificially high effect sizes that don't transfer. The walk-forward evaluation, by strictly separating training from test data, reveals this overfitting. This is why the paper's headline result is the walk-forward Berry Phase Rate ($d = 0.72$), not the offline leader.

Orthogonal Crisis Coverage

Different geometric channels excel at different crises. The best geometric channel per crisis improves roughly +25% over any single fixed method on novel crises, while a rigid detector like CUSUM collapses -73%. This complementarity is the strongest argument for the geometric approach: a single QCML embedding yields multiple independent crisis signatures.

Caveats & Honest Limitations

Reduced Purity is fragile on holdout: $d = 0.83$ offline, $d = 0.26$ on the post-2021 holdout. It overfit to the retrospective panel. The paper flags this explicitly.

HPO bias: the walk-forward result of $d = 0.72$ includes nested HPO. An estimated +0.415$d$ boost may be attributable to HPO; the paper includes this caveat in the methods section.

Computational cost: each Berry curvature evaluation requires 4 Hamiltonian diagonalizations (one per plaquette corner), each $O(n^3)$ in Hilbert dimension. For $\dim \mathcal{H} = 16$, this is manageable; scaling to $\dim \mathcal{H} = 64$+ would require iterative eigensolvers.

Final Comprehension Check
A colleague proposes replacing the random Hermitian operators $\{A_k\}$ with commuting diagonal matrices (so $[A_j, A_k] = 0$ for all $j, k$). This would make the computation faster since $H(x)$ is already diagonal. What is the fundamental problem with this proposal?
A Diagonal matrices aren't Hermitian
B The z-score normalization would fail
C All Berry curvature vanishes identically ($F_{ab} = 0$ everywhere) and reduced-state purity becomes trivial ($\mathcal{P} = 1$), destroying the geometric content
D The spectral entropy would diverge
When all $A_k$ commute, they share a simultaneous eigenbasis. The ground state $|\psi(x)\rangle$ is always a basis vector (it just selects the eigenvalue combination closest to $x$), so the state path consists of discrete jumps between basis vectors rather than smooth rotations on the manifold. The Berry connection becomes flat ($F_{ab} = 0$), the bipartite entanglement vanishes ($\mathcal{P} = 1$), and most of the geometric structure disappears. The entire QCML construction depends on the non-commutativity of the operators creating "frustration" in the ground state, which is what generates nontrivial geometry. This is the quantum-inspired insight: non-commuting observables create richer geometric structure than any classical (commuting) embedding.
